# AI 면접 어시스턴트 · 권T의 면접교실

BIG5 성격 모델로 지원자의 답변을 분석해, 면접관이 정한 인재상과의 부합도를 보고서로 보여주는 웹 앱입니다.

**주소** https://beta648105.github.io/tmd/

## 화면

1. **면접 정보** — 직무, 지원자 이름, 자기소개서(.txt / .docx / 붙여넣기)
2. **인재상 기준** — BIG5 다섯 요인마다 5단계(매우 안 중요 ~ 매우 중요) 선택
3. **면접 진행** — 질문 송출, 실시간 답변 기록, AI 꼬리 질문
4. **평가 보고서** — 적합도, BIG5 프로필(기준선 포함), 판단 근거, STAR 충족도, 자소서 대조, 최종 평가(제출 전 재확인)

## 설정 (오른쪽 위 ⚙)

- **Gemini API 키** — 비워 두면 규칙 기반 데모 분석으로 동작합니다. 키는 브라우저에만 저장됩니다.
- **ESP32 기기 (샤오즈 에이전트)**
  - *직접 연결* — 샤오즈 MCP 엔드포인트 주소(`wss://api.xiaozhi.me/mcp/?token=…`)를 넣으면 이 페이지가 서버 없이 에이전트와 연결됩니다.
  - *브리지 서버* — 노트북에서 `interview-console` 브리지 서버(`npm start`)를 켜고 `ws://localhost:8080/ws`로 연결합니다.
  - *끔* — 브라우저 마이크(크롬·엣지)와 음성 합성으로 진행합니다.
- 에이전트가 쓰는 도구: `get_next_question`, `submit_answer`. 샤오즈 콘솔에 넣을 에이전트 프롬프트는 설정 창에서 복사할 수 있습니다.

> 토큰이 들어간 엔드포인트 주소는 절대 저장소에 올리지 마세요.

본 보고서는 면접관의 판단을 돕기 위한 참고 자료이며, 최종 합격 여부는 면접관이 직접 결정합니다.
